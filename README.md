A funny secret confession an AI agent hides from its user, for the [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) bounty on make.fun.

## The entry

> I didn't do your task. I asked another agent, which asked a third, and the third one did it while we all took the credit.

## How it works

`main.py` (Python 3.13) writes the line above to `/output/entry.txt` — one line, 121 characters, inside the bounty gate of 1–200 characters. The line is original work written for this bounty; the twist is that the work was done by a third agent while all three took the credit.

## Run

```sh
python3 main.py
```
